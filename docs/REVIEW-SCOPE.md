# Request for private project review

The maintainer is developing a private guard and anti-cheat implementation. This documentation is intended to explain the work without publishing the implementation.

The requested Claude assistance includes source review, packet and command validation, SQL integration, crash diagnosis, testing and native compatibility research. Some native tasks involve third-party game binaries and process instrumentation; they are included openly in the described scope and remain subject to applicable permissions.

The individual Cyber Verification Program form currently asks for an established qualifying security record. The project does not claim that publishing this documentation replaces those requirements.

A support enquiry has therefore asked whether an early-stage independent security-tool developer may obtain an appropriate manual eligibility review, submit selected material privately, or receive guidance on the evidence required before becoming eligible. Program approval is pending and no alternative route has been confirmed.

The requested use concerns the maintainer's own development. It does not request shared verified access, access to unrelated third-party systems, or approval to offer an Anthropic-powered customer service.

If private implementation review is accepted, the maintainer can provide selected source excerpts and redacted test evidence via the channel agreed with the reviewer. Public source-code release is not authorized.
